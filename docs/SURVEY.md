## Integration decisions

- DOVE, SparkVSR and QuantVSR wrappers are audited for input handling and result association, rather than copied wholesale.
- BasicSR is an independent differential reference for classical formulas. PyIQA supplies the five non-classical image metrics; original metric repositories remain attribution sources.
- DOVER, FAST-VQA/FasterVQA and RAFT use manually installed, commit-pinned source checkouts. Their model inference runs under the network guard.
- For projects without a verified independent evaluation entry point, the toolkit supports their generated outputs through generic paths. This is not a claim to reproduce their paper tables.
- A model accepting arbitrary size does not establish arbitrary scale, alignment with GT, or feasibility of native-resolution RAFT on limited VRAM.

## Metrics excluded from the default set

| Candidate | Why not a default | Official source |
|---|---|---|
| VBench | Generation-oriented dimensions; requires multiple additional models and a separately specified sampling protocol. | https://github.com/Vchitect/VBench |
| FID / FVD | Distribution metrics require matched sampling populations, enough clips, fixed feature extractors and dataset-level aggregation. | https://github.com/bioinf-jku/TTUR / https://github.com/google-research/google-research/tree/master/frechet_video_distance |
| VMAF | Requires explicit display/model, scaling and pixel-format choices; not interchangeable with restoration fidelity. | https://github.com/Netflix/vmaf |
